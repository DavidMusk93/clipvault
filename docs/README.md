# ClipVault docs

Flowkit 版式：`designs/` · `references/` · `reports/`。
格式门禁：`scripts/check-doc-guard.sh`（flowkit validate_docs）。

| 目录 | 内容 |
| --- | --- |
| `designs/` | 产品/架构设计（taste、会话后端、web 前端、cc 记忆层、clip-link、url-archive） |
| `references/` | 使用与运维参考（agent-api-v1、archive-render、ostore、trae-hooks、session-analysis、notebase-shadow） |
| `reports/` | 事故与验收叙事（`YYYY-MM-DD-*`） |

入口：`AGENTS.md`（仓库法）→ 各篇 doc 的 front-matter `applies_to` 标注生效面。
